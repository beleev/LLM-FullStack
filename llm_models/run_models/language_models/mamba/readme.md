# Mamba (SSM)

- 选择性状态空间模型 (Selective State Space Model), 非注意力架构.
- 线性序列复杂度, 适合长序列建模.
- 对应论文: Mamba (Gu & Dao, 2023).

## 运行命令

### 推理

```bash
python -m llm_models.run_models.language_models.mamba.infer_mamba
```

### 训练

```bash
python -m llm_models.run_models.language_models.mamba.train_mamba
```
